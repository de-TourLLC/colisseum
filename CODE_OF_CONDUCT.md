# Code of Conduct

## What Colisseum is

Colisseum is a Lua/Luau source-code obfuscator. It transforms readable code into a form that is harder to reverse-engineer. It is **not** encryption, **not** access control, and **not** a guarantee against deobfuscation.

## Acceptable use

By using this software you agree:

1. **No illegal use.** You will not use Colisseum to obfuscate code intended for malware, exploits, unauthorized access, fraud, or any activity that violates applicable laws. The tool is meant for protecting your own intellectual property and legitimate code.

2. **You are responsible.** Whatever you obfuscate and distribute is your responsibility — not ours. You are accountable for compliance with all applicable laws and platform terms of service.

3. **No liability.** The Colisseum developers and contributors are **not responsible** for any damage, legal consequences, or losses resulting from the use or misuse of this software. You use it entirely **at your own risk**. See [SECURITY.md](SECURITY.md) and [PRODUCTION.md](PRODUCTION.md) for details.

## Reporting issues

If you find a bug, security vulnerability, or have a problem with the tool, open an issue on the [GitHub repository](https://github.com/anomalyco/opencode/issues). For security vulnerabilities, use GitHub's **Private Vulnerability Reporting** under the Security tab — do not open a public issue.
